# Weekly Meal Prep Generator

This is a simple, high-protein meal prep generator designed to help you decide what to cook for the week. 

## Features
- **Randomized Selection:** Pick a random meal prep idea from a curated list of 15 high-protein recipes.
- **Bean-Free & Asparagus-Free:** Tailored to your specific food preferences.
- **Clear Instructions:** Provides ingredients for 5 servings and step-by-step cooking directions.

## Built With
- **Python**
- **Streamlit** (for the web interface)

## How to run locally
1. Clone this repository.
2. Install the requirements: `pip install -r requirements.txt`
3. Run the app: `python -m streamlit run app.py`
